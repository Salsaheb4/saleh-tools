# salsaheb.sh /tools

Personal pentest command & payload reference → **https://tools.salsaheb.pages.dev**

Single-page, searchable cheatsheet in the `saleh.sh` terminal design system.
Nmap · fuzzing (gobuster / feroxbuster / ffuf) · web payloads (SQLi / XSS) · Linux privesc.
More (AD, pivoting, Windows, notes) added over time.

- Press <kbd>/</kbd> to search everything. Click any command to copy.
- All content lives in [`src/data/tools.ts`](src/data/tools.ts).
- Editing + deploy guide: [`COMMANDS.md`](COMMANDS.md).

Built with Astro. Sibling of the portfolio at [salsaheb.pages.dev](https://salsaheb.pages.dev).
